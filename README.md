## Getting started

Run these commands from the repository root in Linux or WSL:

```bash
bash Linux/system_report.sh
bash ShellScripts/number_report.sh 5
python3 API/fetch_api.py
```

See each directory's README for further instructions. The scripts and API example are starter implementations; run them yourself and capture your own results before submission. The system profile and profile screenshots must reflect your actual work. Review the resume before publishing.
